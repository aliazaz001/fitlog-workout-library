
FitLog is a responsive workout planner web application. Users can browse workout exercises, view full details, create a daily workout plan, save workouts for later, and track their exercise time and calories.

 Technologies Used

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Lucide React
- React Hot Toast
- Browser LocalStorage
- FitLog REST API

 Key Features

1. Browse workout exercises from the FitLog API.
2. View a detailed workout page with image, specs, tags, and instructions.
3. Add workouts to Today’s Plan with a maximum limit of 5 workouts.
4. Save workouts for later in the Saved tab.
5. Dynamic Plan and Saved counters in the navbar.
6. Sort workouts by duration, calories, or rating.
7. Mark planned workouts as done or remove them.
8. Toast notifications for add, save, remove, and done actions.
9. Responsive design for mobile, tablet, and desktop.
10. Loading animation and custom 404 page.
